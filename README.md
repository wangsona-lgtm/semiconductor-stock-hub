# SEMI·PULSE 半導體股票分析終端

結合 **台股半導體供應鏈** 與 **美股費城半導體指標** 的互動式深色科技看盤與投資分析網站，支援 **台股紅漲綠跌慣例**、K 線技術指標、產業鏈估值對比與多股相對強弱走勢分析。

## 核心功能

1. **技術分析終端（Technical Terminal）**
   - 互動式 **K 線圖 / 收盤趨勢圖** 切換，支援 **1M / 3M / 6M / 1Y** 時間區間縮放
   - 均線疊加開關：**MA5 / MA20 / MA60 / 布林通道 BB(20, 2)**
   - 副圖指標切換：**成交量（紅漲綠跌）/ RSI(14) / MACD(12, 26, 9)**
   - 十字游標即時顯示單日 OHLCV 與各項技術指標數值
   - 自動技術面訊號診斷（均線排列、黃金/死亡交叉、RSI 強弱區間、MACD 動能）

2. **半導體供應鏈全景與基本面矩陣**
   - 依 **IC 設計 → 晶圓代工 → 封裝測試 → 設備材料 → 美股費半指標** 分群檢視
   - **P/E 本益比 × 近 20 日報酬率** 估值動能四象限散點圖
   - 支援全欄位排序與即時篩選的基本面／技術面比較表（P/E、P/B、殖利率、各期報酬、RSI、季線乖離率）

3. **多股走勢對比與強弱排行**
   - Base-100 相對報酬率疊圖（內建「台積電雙雄」、「AI ASIC 設計」、「晶圓與設備」預設組合與自由勾選）
   - 單日 / 5日 / 20日 / 60日 漲跌幅強弱勢排行榜

4. **自選股管理與資料匯出**
   - 星號收藏自選股（儲存於瀏覽器 `localStorage`）
   - 一鍵匯出 UTF-8 BOM 格式的 CSV 分析報表（Excel 直接開啟不亂碼）

## 資料來源與自動更新

- **台股上市估值**：臺灣證券交易所（TWSE `BWIBBU_ALL`）
- **台股上櫃估值**：櫃買中心（TPEx OpenAPI）
- **歷史 K 線與美股報價**：Yahoo Finance API
- **排程更新**：透過 `.github/workflows/update-data.yml` 於每個交易日台股盤後及美股收盤後自動更新 `data/stocks.json` 與 `data/stocks.js`。
